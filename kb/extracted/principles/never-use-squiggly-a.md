# Never Use the Squiggly "a"

In all WordPets content, always use the single-story "a" (ɑ) that children actually write — never the double-story typographic "a" (a).

## The rule

This is what Ilana calls a "cardinal sin." The double-story "a" that appears in most computer fonts is not what children learn to write. They learn and recognize the single-story form. Using the wrong one creates confusion between what they see on screen and what they write on paper.

## Where this goes wrong

Red Cat Reading / Kids vs Phonics sometimes uses the double-story "a" in their materials. Ilana flagged this as a mistake that should not be reproduced.

## Application to WordPets

- Choose fonts that use single-story "a" for all child-facing text
- Audit every font used in the app for this
- This applies to ALL letter displays: phonics cards, spelling words, reading passages, UI labels that children interact with
- Teacher-facing dashboard can use normal fonts
